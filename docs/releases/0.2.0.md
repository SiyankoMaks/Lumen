## Установка

Перенесите APK на телефон и откройте его. При необходимости разрешите установку
из выбранного файлового менеджера. В Lumen откройте «Ещё», введите ключ Polza
и выберите модель с поддержкой JSON Schema. Записи работают локально без сервера;
AI требует интернета и оплачивается по тарифу Polza.

Каталог `E:\Lumen-build\signing` содержит ключ подписи и пароль: сохраните его
для будущих обновлений. Не переносите эти файлы вместе с APK и не коммитьте их.
