# Решения и открытые вопросы

- Более новый выбранный дизайн v2 имеет приоритет над временными правилами ТЗ
  и светлыми вариантами на изображении.
- Draw.io ER содержит placeholders; конкретная схема следует master-ТЗ.
- BPMN показывает синхронный ответ AI; master-ТЗ требует worker. Сохранение
  записи отделено от фонового анализа, AI запускается явно с согласия пользователя.
- Первый клиент: Android/iOS Expo; web не является обязательной платформой.
- Минимум для паттерна: три различные записи. Это консервативное начальное
  допущение, которое требует продуктовой проверки, а не статистическая значимость.
- Фото/голос, уведомления и Evie требуют отдельных контрактов и не должны
  выглядеть работающими до появления реальной реализации.
- Production домен, TLS, почта для восстановления пароля, AI credentials,
  retention policy и store signing не предоставлены. Секреты задаются окружением.
- На рабочей машине найден рабочий Python 3.11; зарегистрированный Python 3.14
  недоступен. Production образ будет Python 3.12; локальная проверка совместима с 3.11.
