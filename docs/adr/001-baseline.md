# ADR 001 — стек и shared revision envelope

Статус: серверная часть решения заменена [ADR 003](003-standalone-polza.md)
для автономного Android-клиента. Ниже сохранено исходное решение v0.1.

Принято: Expo SDK 57 / Router / SQLite / SecureStore, Python FastAPI / SQLAlchemy
2 / Alembic / PostgreSQL 16. Совместимые native версии взяты из manifest Expo.
Реализация клиента ориентирована на Android/iOS. Будущий web использует тот же REST.

Домен хранится в общей таблице entities с типизированным JSONB content, отдельными
revision/evidence таблицами и ресурсными REST маршрутами. Это разрешённая master-ТЗ
универсальная база AIArtifact; entity.kind задаёт доменный тип, а не произвольный
endpoint для всех операций. Разделение таблиц возможно позже миграциями при
появлении специализированных индексов/аналитических запросов.

Сериализация записей пользователя через row lock выбрана ради корректности
идемпотентности и межресурсных инвариантов. Цена — ограниченная write concurrency
для одного пользователя; для персонального журнала это приемлемый старт.
