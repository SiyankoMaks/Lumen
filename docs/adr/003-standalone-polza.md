# ADR 003 — автономное приложение и прямой Polza API

Дата: 18.09.2026. Статус: принято по прямому указанию пользователя.
Заменяет обязательность cloud backend из ADR 001/002 и исходного master-ТЗ.

## Причина

Пользователю нужен устанавливаемый клиент без расходов на собственный сервер.
AI обслуживает инфраструктура Polza. Оплата запросов Polza остаётся отдельной
от хостинга; приложение не обещает бесплатный AI.

## Решение

- Локальная SQLite — источник истины для записей, revisions, evidence и AI jobs.
- Ключ Polza принадлежит пользователю, вводится в настройках и сохраняется
  через SecureStore. Не в сборке, `.env`, SQLite, экспортном файле или журналах.
- HTTPS запросы только к фиксированному `https://polza.ai/api/v1`.
- UI вызывает application AI service; adapter проверяет ответы, domain проверяет
  evidence и текущие ревизии, repository сохраняет весь результат транзакционно.
- Нет регистрации Lumen, фонового polling собственного API, Redis/PostgreSQL
  или обязательного Docker. Старый backend остаётся историческим опциональным кодом.
- Автоматических платных повторов нет. Прерывание/timeout показываются явно;
  повтор — новое осознанное действие пользователя. Статистика использования
  сохраняется из фактического ответа провайдера, без выдуманной цены.
- Экспорт/импорт локального архива заменяет облачное хранение для резервных копий.

## Миграция и границы

Сохраняем старые entities/history/outbox/conflicts, добавляем автономные таблицы
и revisions. Старый outbox не отправляется. Нельзя автоматически считать старый
локальный snapshot доказательством конкретной облачной ревизии. Такие источники
остаются архивными, пока точная версия отсутствует.

Пользователь выбрал Android APK. Release содержит JS bundle и работает без Metro.
Подпись хранится отдельно от Git; повторные выпуски используют тот же ключ.
Межустройственная синхронизация без сервера не обещается.

## Проверка

Offline CRUD/revisions, миграция старой БД без потерь, evidence/stale-source checks,
отмена/неопределённый результат платного запроса, валидация backup, secure key storage,
статистика, UI и устанавливаемая release-сборка на выбранной платформе.

Контракт провайдера: https://polza.ai/docs/gaidy/chat-completions и
https://polza.ai/docs/gaidy/structured-output. Поле `cost_rub` (либо `cost`)
учитывается как фактическая стоимость в рублях; отсутствие поля не означает ноль.
