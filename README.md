# Lumen

Автономный Android-журнал: записи → наблюдения → паттерны → гипотезы → эксперименты.
SQLite хранит данные на телефоне. AI вызывается напрямую через Polza; собственный
сервер, регистрация Lumen и Docker для приложения не нужны. Запросы Polza платные
по тарифу выбранной модели.

## Использование

Подписанный APK 0.2.0 собран 21.09.2026: `E:\Lumen-build\artifacts\Lumen-0.2.0.apk`.
Android 7.0+ (ARM64/ARMv7). [Проверки и контрольная сумма выпуска](docs/releases/0.2.0.md).

Установите release APK, откройте «Ещё», введите свой ключ Polza и идентификатор
модели либо выберите модель из каталога. Ключ хранится в Android SecureStore,
не включается в APK, Git или резервную копию. Для анализа нужна модель,
поддерживающая structured output (JSON Schema).

Записи сохраняются без интернета. Отправка выбранных сохранённых версий в Polza
требует подтверждения. AI-выводы создаются черновиками с источниками и историей.
При изменении исходной записи во время анализа результат не применяется.
При отмене, таймауте или закрытии приложения платный запрос не повторяется
автоматически; уже отправленный запрос может быть тарифицирован провайдером.

«Ещё» показывает число записей, запросов, токены и подтверждённую стоимость
в рублях. Неизвестная стоимость отмечается отдельно. Экспорт JSON содержит
записи, удалённые записи и точные локальные версии; импорт объединяет совпадающие
данные и целиком отклоняет конфликтующий архив. Ключ и статистика запросов
не переносятся. Экспорт сохраняет JSON в выбранную вами папку. Храните резервные
копии отдельно от телефона: удаление приложения
удаляет локальную БД. Автоматический Android backup отключён.

## Разработка и проверки

Node.js 24, JDK 21, Android SDK. Подробности: [сборка APK](docs/ANDROID_BUILD.md).

```sh
npm ci
npm run mobile
npm test
npm run test:ui
npm run typecheck
npm run metrics
```

Рабочие слои: экраны → AIService → доменные схемы / LocalRepository →
SQLite, SecureStore, Polza HTTPS adapter. Runtime клиента не вызывает старый API.
Исторический backend и его контракты оставлены для сохранения истории v0.1;
старые серверные инструкции не относятся к автономному Android-клиенту.
